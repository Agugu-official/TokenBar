## Fixes

- **The Discord agent picker now lists the agents you have used**, rather than every agent TokenBar recognises. It offered a row for agents you have never run and for ones you had hidden; naming one of those left the presence empty and said nothing about why. One agent stays listed regardless: the one your setting already names, even after you hide it — otherwise nothing would be ticked while the setting still points at it. On a fresh install with no usage the only choice is "whichever client you used most", which is the honest answer when there is nothing to publish.
