## Features

- **Eight more agents are tracked: ZCode, Augment Code, Hindsight, Muse Code, Reasonix, Kimchi, Senpi and Oh My Pi.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  Each is listed under its own name and icon. ZCode is read from its v2 database (`~/.zcode/cli/db/db.sqlite`). Kimchi is read from `~/.config/kimchi/harness/sessions` and Senpi from `~/.senpi/agent/sessions`, or from the folders their `KIMCHI_CODING_AGENT_DIR` and `SENPI_CODING_AGENT_DIR` settings name. Hindsight usage only appears after you install the upstream tokscale CLI and run `tokscale hindsight sync`, because Syrtis reads the usage files that command writes. Kimi Work sessions, the Kimi Code sessions inside the Kimi desktop app, now count toward Kimi.

- **Oh My Pi is counted on its own instead of as Pi.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  `~/.omp/agent/sessions` used to be read as Pi. Its usage now moves from Pi to Oh My Pi, so Pi's history drops by the same amount and totals stay the same. One exception: a record present in both `~/.pi` and `~/.omp`, such as a session copied over when moving to Oh My Pi, used to count once and now counts once for each agent.

- **More Antigravity accounts, each with its own quota card.** [#458](https://github.com/Nanako0129/syrtis/pull/458) [#459](https://github.com/Nanako0129/syrtis/pull/459) [#460](https://github.com/Nanako0129/syrtis/pull/460)

  Settings → General → Antigravity accounts has a "Capture current agy login" button: sign agy in to another Google account, press it, then sign agy back in to your main account. The account gets its own Antigravity card, labeled by its email, showing the same four rows that agy's `/usage` prints. Capture reads agy's saved Google login once, keeps a copy in this Mac's login keychain, and uses it only with Google's token and Cloud Code quota services. Remove deletes only that copy; Google keeps accepting the sign-in until you revoke it in your Google Account.

  "Capture accounts agy signs into automatically" is off by default. When on, Syrtis captures the account agy is signed into, and again each time agy's sign-in changes; the account agy is using right now is shown once, under its email, when Antigravity's quota is read through agy. Turning it off keeps the accounts already captured, and an account you remove is not captured again until you press the button.

- **Less memory on warm scans, most of all with one agent selected.** [#463](https://github.com/Nanako0129/syrtis/pull/463)

  A scan now loads each agent's cache only when it reaches that agent, and frees it afterwards for every agent except Claude. On the maintainer's usage, peak memory of a scan with a warm cache went from 329.0 to 301.9 MiB (−8.2%) for all agents, and dropped 88% for Cursor alone, 32% for Claude alone and 29% for Codex alone. A scan with no cache yet uses the same memory as before. Results are the same.

## Fixes

- **Long GPT-5.4 to GPT-6 requests could be priced at the short-context rate.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  Once a request's input and cached input pass 272K tokens, OpenAI bills the whole request at its long-context rate. Syrtis now does the same, including when a provider's price list lacks the long-context rate and the model's own list has it. Measured on the maintainer's usage with prices held fixed:

  | Agent | Model | Before | After |
  | --- | --- | ---: | ---: |
  | Claude Code | `gpt-5.6-sol` | $355.25 | $449.17 |
  | Codex | `gpt-5.6-sol` | $5,901.37 | $6,397.37 |
  | Codex | `gpt-6-astra` | $196.53 | $320.60 |
  | OpenCode | `gpt-5.4` | $79.94 | $86.29 |

  Token counts did not change.

- **OpenRouter prices were taken from the discounted Flex tier.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  For 32 Gemini 3.x, GPT-5.x and GPT-6.x models, OpenRouter lists a half-price Flex tier first, and Syrtis stored that rate. It now stores the rate OpenRouter lists for the model, which doubles the price of 31 of them where their price comes from OpenRouter. This takes effect the next time prices refresh. On the maintainer's usage it moved one model, `gpt-6-astra`, from $5.91 to $11.82 under Claude Code and from $98.27 to $196.53 under Codex. For `gpt-5.6-sol-pro` the listed rate is OpenRouter's Fast tier, so it is now priced at twice its standard rate.

- **Kiro showed token estimates for requests it reports in credits.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  A Kiro request that reports credits is now priced at $0.04 per credit, on the turn it happened.

- **Some model names were priced as another model, or not at all.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  `kimi-for-coding` was priced as Kimi K2.5 and is now priced as K2.7 Code. Kimi Work's `k2d6-agent` and `k3-agent` were priced as xAI's Grok 4.20 and now take Kimi's rates. `k3`, `k3-256k` and GitHub Copilot's `claude-opus-41` had no price and now have one, and `claude-sonnet-4-0` is priced as Claude Sonnet 4.

- **A Pi session file that began with a byte-order mark was skipped.** [#461](https://github.com/Nanako0129/syrtis/pull/461)

  Such a file is now read like any other.

- **Grok and Antigravity tabs showed past windows and a heatmap instead of the window history.** [#457](https://github.com/Nanako0129/syrtis/pull/457)

  Their Quota view now ends with the same window history table as Claude, Codex and the other tabs. Grok Bot's past windows remain on the Quota view for all agents.

- **The "Quota summary" switch under Settings' Overview cards was not translated in Chinese.** [#464](https://github.com/Nanako0129/syrtis/pull/464)

  Its label now matches the translation tables, so it shows in Traditional and Simplified Chinese, and in English it reads "Quota summary" instead of "Quota Summary".

The first scan after updating takes longer if you use Kiro or Pi, while their sessions are read again.
