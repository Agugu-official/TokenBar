Features:
- Releases are signed with a Developer ID and notarized by Apple. macOS opens a downloaded Syrtis without a Gatekeeper warning, and the Homebrew cask no longer removes the quarantine flag. Installed copies update in the app as before.
- Each release has an installer DMG (Syrtis-2.2.0.dmg) on the release page. In-app updates and the Homebrew cask keep using the tar.gz.
- A new animated menu bar icon, Sand shoal: sand falls onto a dune while a current carries grains away, at 24 fps in four levels set by the live token rate (50K, 300K and 1.5M tokens per minute at the default pace). Suggested on Discord by charliie.
- Animated icons follow a new speed curve: 2 fps up to 50K tokens per minute, then a log curve to 40 fps at 3M. A pace choice under Settings -> Menubar icon scales it: Light reaches full speed at 600K, Moderate (the default) at 3M, Heavy at about 10M.
- Setup cards at the top of the Overview cover agent tabs, the menu bar icon and text, animation pace, usage attribution, start at login and the Discord profile. Existing users see them once too; "Skip setup" answers the rest. The Discord card replaces the launch-time Discord alert and does not turn the profile on.

Fixes:
- With no quota reading, the menu bar gauge looked like a full allowance. It is now drawn faded with a diagonal slash.
- A reading more than 30 minutes old greyed the gauge but not the "Quota left" title; the title now turns the same grey.
- A new Settings page, or a new tab or view in the dashboard, now starts at the top instead of keeping the previous scroll position.
- Two Settings hints described behavior the app does not have: Data refresh and the Overview card order. The Settings hints were rewritten in plainer language.
